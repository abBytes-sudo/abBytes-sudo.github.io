04 · How I work

I start with the team, not with code.

  1. ListenSit with the team and watch the real work, in the words they use.
  2. MapWrite down what feeds what: leads, listings, calls, quotes, tasks.
  3. DecideAgree the rules and what ships first, before anything is built.
  4. BuildAI coding tools write the code under my direction. I test every change on desktop and phone.
  5. LaunchMove the old records across, train the team, then measure how the system is used.
