01About me

I’m Abhishek. I turn messy operations into one system.

For 4 years I’ve led operations and built systems for businesses in property, construction & interiors, and fitness. I sit with the team, map how the work really flows, and build the system they run on: the CRM, the website and the automation between them. Then I move the old records across, train the team, and stay until it’s simply how they work.

How I work, start to finish

  1. 01Listen

    Sit with the team and watch the real work, in the words they use.

  2. 02Map

    Write down what feeds what: leads, listings, calls, quotes, tasks.

  3. 03Decide

    Agree the rules and what ships first, before anything is built.

  4. 04Build

    AI coding tools write the code under my direction. I test every change on desktop and phone.

  5. 05Launch

    Move the old records across, train the team, then measure how the system is used.

Working with me

  • →I’ll ask “why” a lot. It’s how I find the rule behind the work.
  • →I won’t oversell a feature nobody has used yet.
  • →I show real numbers from live systems.
  • →Quiet in the meeting, thorough in the plan.

Now

Studying for a Bachelor of Computer Applications with an Agentic AI specialisation, and learning to program alongside building production systems. I’m starting with C, so I can read the code my tools write as well as direct it.
